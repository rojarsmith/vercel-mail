private-automation

A private email-sending service for its owner's own automated workflows.

Privacy Policy Source code

What this app does

private-automation is a small server-side API that sends email messages from its owner's Gmail account using the Gmail API. The owner's own backend systems call this API to send notifications, reports and other messages (plain text, HTML, inline images and attachments).

How it uses Google data

  • The app requests permission to send email on behalf of the single Google account that authorized it (the owner).
  • It does not read, search, modify or delete any existing email, contacts or other Google data.
  • Message content is passed directly to the Gmail API to be sent and is not stored by the app.
  • The API is protected by a private key; it is not offered to the public and has no user sign-up.

Who can use it

This app is operated for personal use by its owner. There are no public user accounts and no login is required to read this page. See the Privacy Policy for details on data handling.
